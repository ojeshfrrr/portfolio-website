# Uiverse interaction adaptations

The item source panes and individual MIT notices were reviewed before implementation. Attribution for each selected source appears below.

- https://uiverse.io/nikk7007/nasty-wasp-56 — button by nikk7007 (Nikolas). Adapted its positioned pseudo-element fill into a short horizontal transform for MYOVIO primary CTAs. Removed skewed panels, uppercase text, original green palette, brightness filter, and scaling.
- https://uiverse.io/alexruix/slippery-frog-10 — input by alexruix (Alex Ruiz). Adapted its border/background focus treatment and restrained surrounding ring. Retained MYOVIO labels, native controls, visible keyboard outlines, error associations, sizing, and palette.

These adaptations live in `src/app/ui-polish.css`. Link arrows and project framing were written for MYOVIO. The menu icon adapts the three-bar-to-close transition from Cevorob's hamburger/checkbox element; its native checkbox, 40 × 30 sizing, black color, and heavier strokes were replaced with spans inside MYOVIO's existing semantic button.

- https://uiverse.io/Cevorob/good-wolverine-51 — checkbox/menu icon by Cevorob. Adapted the three horizontal strokes and open-to-close transformation for the existing accessible navigation button. No checkbox or additional JavaScript was copied.
